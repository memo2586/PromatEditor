# ComfyUI Prompt Editor Bridge 1.4.0

为 Prompt Editor 提供提示词读取、参数与模型控制、工作流分组同步、任务提交、进度回传和生成结果关联。

## 安装

将本目录整体复制到 `ComfyUI/custom_nodes/`，重启 ComfyUI 并刷新浏览器。升级时整体更新目录，并使用匹配的编辑器版本。

在工作流中添加「提示词编辑器 · 提示词与参数」节点。编辑器默认地址为 `http://127.0.0.1:8189`，可在节点中修改。节点的 positive / negative 输出连接到文本编码器，其余 Seed、steps、CFG、采样器、尺寸与批次数输出按工作流需要连接。

编辑器和 ComfyUI 应运行在同一台电脑；浏览器需要打开目标工作流。首次配置时在编辑器读取节点和分组，选择需要控制的目标。

## 功能

- 读取积极 / 消极提示词和生成参数，校验未完成语法与非法参数。
- 按节点控制 LoRA Manager、标准 / LoRA Manager UNet 和 VAE 加载器；LoRA 支持独立 Model / CLIP 权重。
- 同步 Fast Groups Bypasser 分组开关。
- 通过浏览器现有队列链路提交任务，锁定提交时的参数快照，返回进度和精确关联的结果。
- 中断当前任务、取消指定等待任务或清空等待队列。
- 读取 LoRA 模型库及已安装 LoRA Manager 的可用资料。

提交任务时浏览器页面需保持可连接；刷新页面或更换工作流后，旧请求不会提交到错误的页面。任务受理状态不明时只核对队列和历史，不自动重复提交。

## 示例与排查

- [`示例-参数与分组.json`](../示例-参数与分组.json)：参数与分组连线示例。
- `python ../check_connection.py`：使用扩展内置客户端检查编辑器默认连接；也可在命令后提供编辑器 URL。
- 端口冲突时，可用 `PromptEditor.exe --bridge-port 8190` 启动，并同步修改节点地址。
- 读取不到节点或目录时，检查后端是否重启、浏览器是否刷新以及扩展文件是否整体更新。
